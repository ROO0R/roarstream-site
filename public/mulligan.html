Mulligan Mode

These rules are subject to change and abandonment at literally any time.

1
Activation

We play normally until first death.
Once that happens, Mulligan Mode can be activated.
This is at Roar's discretion.
Mulligan Mode is in no way required if he chooses to play 'fairly'.

2
The Mulligan

Mulligan Mode allows for a rewind to fix a mistake.
The only limit on how far back I can rewind is pride.
Only one mulligan can be used per life.
Dying again after using a mulligan acts as a normal death.

Terrible game physics or controller issues that are objectively not Roar's fault -
like accidentally sliding into a pit or glitching into the void -
are a free mulligan at any time regardless of Mulligan Mode.

3
Game Over Bonus Mode (as applicable)

After a Game Over, one save state per Mulligan Mode is allowed - usually near bosses.

Mulligans can still be used on a loaded save state.

Once the save state is popped, it cannot be updated until Mulligan Mode is off.

4
Goal Achieved

Once the level/boss/whatever is beaten, Mulligan Mode is automtically turned off until the next death.

The 2 Hour Caveat

Once the stream passes the two hour mark,
(or, at Roar's discretion, if the entertainment value of the stream drops into a goddamned fjord)
Mulligan Mode rules are temporarily modified to:

“I can do whatever I want.”
